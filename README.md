# Jessica Bronson

Developer, digital creator, and seamstress building practical software, creative tools, and immersive game systems.

## About me

My development journey began with game modding and grew into desktop applications, creative platforms, workflow systems, interactive experiences, and learning-through-play projects. I bring hands-on knowledge of sewing, manufacturing workflows, visual design, game systems, and creative production into the software I build.

I especially enjoy work that feels like play: projects where experimentation, creativity, and practical problem-solving lead to something useful.
